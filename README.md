# Monopoly
This Monopoly clone was created in python as a final project for Penn States CMPSC 131 class.

# Requirements
Python 3.9 or higher
Pygame library installed. To install, please follow the guide on the [pygame website](https://www.pygame.org/wiki/GettingStarted).

# Usage
Run main.py from the project folder after downloading from the latest release section.

# Features
* 2-4 People can play at once.
* Purchasing properties with a display for who owns which ones.
* Chance cards
* Community Chest Cards
* Jail, which can be left by either rolling doubles or waiting 3 turns in jail. (Displays how many turns you've been in jail after each turn)
* Taxes! (A personal favorite)
* Bankruptcy and transfering if property to whoever bankrupt the player. If a player did not bankrupt someone, the property becomes available again.
* Displays the winner at the end of every game!
